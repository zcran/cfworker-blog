## 和为 K 的最少斐波那契数字数目

给你数字 k ，请你返回和为 k 的斐波那契数字的最少数目，其中，每个斐波那契数字都可以被使用多次。

斐波那契数字定义为：

F1 = 1
F2 = 1
Fn = Fn-1 + Fn-2 ， 其中 n > 2 。

数据保证对于给定的 k ，一定能找到可行解。


```
impl Solution {
    pub fn find_min_fibonacci_numbers(mut k: i32) -> i32 {
        // 预生成的斐波那契数，降序排列；贪心每次取不超过 k 的最大斐波那契数
        const FIB: [i32; 45] = [
            1836311903, 1134903170, 701408733, 433494437, 267914296, 165580141,
            102334155, 63245986, 39088169, 24157817, 14930352, 9227465, 5702887,
            3524578, 2178309, 1346269, 832040, 514229, 317811, 196418, 121393,
            75025, 46368, 28657, 17711, 10946, 6765, 4181, 2584, 1597, 987,
            610, 377, 233, 144, 89, 55, 34, 21, 13, 8, 5, 3, 2, 1,
        ];

        let mut count = 0;
        for &f in &FIB {
            // 同一斐波那契数可重复使用，故用 while 而非 if
            while k >= f {
                k -= f;
                count += 1;
            }
            if k == 0 {
                break;
            }
        }
        count
    }
}
```
