## 计算力扣银行的钱

Hercy 想要为购买第一辆车存钱。他 每天 都往力扣银行里存钱。

最开始，他在周一的时候存入 1 块钱。从周二到周日，他每天都比前一天多存入 1 块钱。在接下来每一个周一，他都会比 前一个周一 多存入 1 块钱。

给你 n ，请你返回在第 n 天结束的时候他在力扣银行总共存了多少块钱。


```
impl Solution {
    pub fn total_money(n: i32) -> i32 {
        // 每周存的钱构成等差数列：
        //   第 k 周（k 从 1 开始）每天存 k, k+1, ..., k+6，周合计 = 7k + 21
        // 因此前 w 整周合计 = 7 * w * (w + 1) / 2 + 21 * w
        // 剩余 r 天为第 w+1 周的前 r 天：每天存 w+1, w+2, ..., w+r
        // 剩余合计 = r * (w + 1) + r * (r - 1) / 2
        let w = n / 7; // 完整周数
        let r = n % 7; // 剩余天数

        // 合并整理后：
        // total = w * (7 * w + 49) / 2 + r * (2 * w + r + 1) / 2
        (w * (7 * w + 49) + r * (2 * w + r + 1)) / 2
    }
}
```
