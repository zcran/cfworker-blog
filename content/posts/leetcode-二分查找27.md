## 鸡蛋掉落

给你 k 枚相同的鸡蛋，并可以使用一栋从第 1 层到第 n 层共有 n 层楼的建筑。

已知存在楼层 f ，满足 0 <= f <= n ，任何从 高于 f 的楼层落下的鸡蛋都会碎，从 f 楼层或比它低的楼层落下的鸡蛋都不会破。

每次操作，你可以取一枚没有碎的鸡蛋并把它从任一楼层 x 扔下（满足 1 <= x <= n）。如果鸡蛋碎了，你就不能再次使用它。如果某枚鸡蛋扔下后没有摔碎，则可以在之后的操作中 重复使用 这枚鸡蛋。

请你计算并返回要确定 f 确切的值 的 最小操作次数 是多少？


```
impl Solution {
    /// 返回确定临界楼层 f 所需的最小操作次数。
    ///
    /// 思路（逆向 DP）：反过来考虑——给定操作次数 t 和鸡蛋数 k，
    /// 最多能覆盖多少层楼？
    ///   设 dp[j] 为用 j 枚鸡蛋、当前操作次数下能确定的最大楼层数。
    ///   每增加一次操作，状态转移为：
    ///       dp[j] = dp[j] + dp[j-1] + 1
    ///   含义：在当前楼层扔一枚鸡蛋，
    ///     - 若碎了，用 j-1 枚鸡蛋往下查，可覆盖 dp[j-1] 层；
    ///     - 若没碎，用 j 枚鸡蛋往上查，可覆盖 dp[j] 层；
    ///     - 加上当前这一层。
    ///   不断累加操作次数，直到 dp[k] >= n。
    pub fn super_egg_drop(k: i32, n: i32) -> i32 {
        // dp[j]：用 j 枚鸡蛋在当前操作次数下能确定的最大楼层数
        let mut dp = vec![0i32; k as usize + 1];
        let mut moves = 0;

        while dp[k as usize] < n {
            moves += 1;
            // 逆序遍历，避免覆盖上一轮的值
            for j in (1..=k as usize).rev() {
                dp[j] += dp[j - 1] + 1;
            }
        }

        moves
    }
}
```
