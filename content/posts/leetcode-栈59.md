## 等量移除后的字符串最小长度

给你一个仅由字符 'a' 和 'b' 组成的字符串 s。

你可以反复移除 任意子字符串 ，只要该子字符串中 'a' 和 'b' 的数量相等。每次移除后，剩余部分的字符串将无缝拼接在一起。

返回一个整数，表示经过任意次数的操作后，字符串可能的 最小长度 。

子字符串 是字符串中一个连续、非空的字符序列。


```
impl Solution {
    /// 返回经过任意次移除等量 'a' 和 'b' 子串后，字符串可能的最小长度
    ///
    /// # 算法思路
    /// 每次移除一个包含相同数量 'a' 和 'b' 的子串，等价于移除等量的 'a' 和 'b'。
    /// 最终剩余的字符串只能包含一种字符（全 'a' 或全 'b'），
    /// 长度等于两种字符数量之差的绝对值。
    ///
    /// # 数学证明
    /// 设 'a' 的数量为 count_a，'b' 的数量为 count_b。
    /// 每次操作移除相同数量的 'a' 和 'b'，因此两种字符的数量差保持不变。
    /// 最终剩余字符串中只能有一种字符，其长度 = |count_a - count_b|。
    ///
    /// # 复杂度
    /// - 时间复杂度：O(n)，统计字符数量
    /// - 空间复杂度：O(1)，仅使用常数空间
    pub fn min_length_after_removals(s: String) -> i32 {
        let count_a = s.chars().filter(|&ch| ch == 'a').count() as i32;
        let count_b = s.len() as i32 - count_a;
        (count_a - count_b).abs()
    }
}
```
