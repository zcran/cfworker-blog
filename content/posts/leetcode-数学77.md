## 覆盖网格的最少传感器数目

给你一个 n × m 的网格和一个整数 k。

一个放置在单元格 (r, c) 的传感器可以覆盖所有与 (r, c) 的 切比雪夫距离不超过 k 的单元格。

两个单元格 (r1, c1) 和 (r2, c2) 之间的 切比雪夫距离 为 max(|r1 − r2|,|c1 − c2|)。

你的任务是返回覆盖整个网格所需传感器的 最少 数量。


```
impl Solution {
    pub fn min_sensors(n: i32, m: i32, k: i32) -> i32 {
        // 一个传感器覆盖边长为 (2k+1) 的正方形区域。
        // 将网格按该边长划分，每个方向需要 ceil(dim / (2k+1)) 个传感器，
        // 两方向相乘即为总数。
        let size = 2 * k + 1;
        ((n + size - 1) / size) * ((m + size - 1) / size)
    }
}
```
