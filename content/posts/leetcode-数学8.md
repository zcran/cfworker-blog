## 逃脱阻碍者

你在进行一个简化版的吃豆人游戏。你从 [0, 0] 点开始出发，你的目的地是 target = [xˇtarget, yˇtarget] 。地图上有一些阻碍者，以数组 ghosts 给出，第 i 个阻碍者从 ghosts[i] = [xˇi, yˇi] 出发。所有输入均为 整数坐标 。

每一回合，你和阻碍者们可以同时向东，西，南，北四个方向移动，每次可以移动到距离原位置 1 个单位 的新位置。当然，也可以选择 不动 。所有动作 同时 发生。

如果你可以在任何阻碍者抓住你 之前 到达目的地（阻碍者可以采取任意行动方式），则被视为逃脱成功。如果你和阻碍者 同时 到达了一个位置（包括目的地） 都不算 是逃脱成功。

如果不管阻碍者怎么移动都可以成功逃脱时，输出 true ；否则，输出 false 。


```
impl Solution {
    /// 判断吃豆人能否在任意阻碍者抓住自己之前到达目的地。
    ///
    /// 关键观察：
    /// - 你和阻碍者每回合都只能移动一格（曼哈顿距离意义上的最短路径长度），
    ///   并且双方可以同时移动、且阻碍者可以采取任意策略。
    /// - 由于移动速度相同，谁能更早到达目的地，取决于谁离目的地的
    ///   曼哈顿距离更小。
    /// - 若某个阻碍者到目的地的曼哈顿距离 ≤ 你到目的地的曼哈顿距离，
    ///   则该阻碍者可以提前或同时到达目的地并拦截你，逃脱失败。
    ///
    /// 因此只要所有阻碍者到目的地的曼哈顿距离都严格大于你的距离，
    /// 就能成功逃脱。
    pub fn escape_ghosts(ghosts: Vec<Vec<i32>>, target: Vec<i32>) -> bool {
        let (tx, ty) = (target[0], target[1]);
        let my_dist = tx.abs() + ty.abs();

        ghosts
            .iter()
            .all(|g| (tx - g[0]).abs() + (ty - g[1]).abs() > my_dist)
    }
}
```
