## 构造有效字符串的最少插入数

给你一个字符串 word ，你可以向其中任何位置插入 "a"、"b" 或 "c" 任意次，返回使 word 有效 需要插入的最少字母数。

如果字符串可以由 "abc" 串联多次得到，则认为该字符串 有效 。


```
impl Solution {
    /// 返回使字符串变为有效（由若干个 "abc" 串联）所需插入的最少字母数
    ///
    /// # 算法思路
    /// 将字符串视为在循环序列 "abcabc..." 中采样，计算相邻字符在循环中的距离差：
    /// - 如果字符相同或循环顺序正确，距离为 0
    /// - 否则需要补足距离，插入缺失的字母
    ///
    /// 关键公式：每个相邻字符对在循环中的距离 = (s[i] - s[i-1] + 2) % 3
    /// 首尾额外距离：从最后一个字符回到 'a' 再补全到第一个字符
    ///
    /// # 复杂度
    /// - 时间复杂度：O(n)，一次遍历
    /// - 空间复杂度：O(1)，仅使用常数空间
    pub fn add_minimum(word: String) -> i32 {
        let bytes = word.as_bytes();
        let mut insertions = 0;

        // 处理第一个字符：需要从 'a' 开始补齐到 word[0]
        // 例如 'b' 需要补 'a'，'c' 需要补 'a','b'，'a' 不需要补
        insertions += (bytes[0] - b'a') as i32;

        // 处理相邻字符对：计算它们之间需要插入的字母数
        for i in 1..bytes.len() {
            // 计算当前字符相对于前一个字符在循环 "abc" 中的距离
            // +2 是为了避免负数取模的问题
            let gap = ((bytes[i] - bytes[i - 1] + 2) % 3) as i32;
            insertions += gap;
        }

        // 处理最后一个字符：需要从最后一个字符补全到 'c'
        // 例如 'a' 需要补 'b','c'，'b' 需要补 'c'，'c' 不需要补
        insertions += (b'c' - bytes[bytes.len() - 1]) as i32;

        insertions
    }
}
```
