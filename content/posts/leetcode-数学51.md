## 倍数求和

给你一个正整数 n ，请你计算在 [1，n] 范围内能被 3、5、7 整除的所有整数之和。

返回一个整数，用于表示给定范围内所有满足约束条件的数字之和。


```
impl Solution {
    pub fn sum_of_multiples(n: i32) -> i32 {
        // 容斥原理：能被 3、5、7 中至少一个整除的数之和
        //   = S(3) + S(5) + S(7)
        //   - S(15) - S(21) - S(35)
        //   + S(105)
        // 其中 S(m) 是 [1, n] 内所有 m 的倍数之和：
        //   S(m) = m * (1 + 2 + ... + n/m) = m * (n/m) * (n/m + 1) / 2
        let sum = |m: i32| m * (n / m) * (n / m + 1) / 2;

        sum(3) + sum(5) + sum(7) - sum(15) - sum(21) - sum(35) + sum(105)
    }
}
```
