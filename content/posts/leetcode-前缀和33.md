## 生成平衡数组的方案数

给你一个整数数组 nums 。你需要选择 恰好 一个下标（下标从 0 开始）并删除对应的元素。请注意剩下元素的下标可能会因为删除操作而发生改变。

比方说，如果 nums = [6,1,7,4,1] ，那么：

选择删除下标 1 ，剩下的数组为 nums = [6,7,4,1] 。
选择删除下标 2 ，剩下的数组为 nums = [6,1,4,1] 。
选择删除下标 4 ，剩下的数组为 nums = [6,1,7,4] 。

如果一个数组满足奇数下标元素的和与偶数下标元素的和相等，该数组就是一个 平衡数组 。

请你返回删除操作后，剩下的数组 nums 是 平衡数组 的 方案数 。


```
impl Solution {
    /// 计算删除一个元素后使数组平衡的方案数
    ///
    /// 平衡数组：奇数下标元素和 == 偶数下标元素和
    ///
    /// 思路：
    /// 1. 初始 total 记录所有元素按原下标的奇偶和
    /// 2. 从左到右遍历，先移除当前元素（total 变为右侧剩余）
    /// 3. 删除后右侧奇偶翻转，判断新数组的奇偶和是否相等
    /// 4. 将当前元素加入左侧，继续遍历
    pub fn ways_to_make_fair(nums: Vec<i32>) -> i32 {
        let mut total = [0i32, 0i32]; // [偶数位和, 奇数位和]
        for (i, &num) in nums.iter().enumerate() {
            total[i & 1] += num;
        }

        let mut left = [0i32, 0i32]; // 当前下标左侧的奇偶和
        let mut ans = 0;

        for (i, &num) in nums.iter().enumerate() {
            total[i & 1] -= num; // 将当前元素从右侧移除

            // 删除后，右侧奇偶翻转，新数组的奇偶和为：
            // 偶数位 = 左侧偶 + 右侧奇，奇数位 = 左侧奇 + 右侧偶
            if left[0] + total[1] == left[1] + total[0] {
                ans += 1;
            }

            left[i & 1] += num; // 当前元素加入左侧
        }

        ans
    }
}
```
