## 统计范围内的逗号 II

给你一个整数 n。

返回将所有从 [1, n]（包含两端）范围内的整数以 标准 数字格式书写时所用到的 逗号总数。

在 标准 格式中：

从右边开始，每 三位 数字后插入一个逗号。
位数 少于四位 的数字不包含逗号。


```
impl Solution {
    pub fn count_commas(n: i64) -> i64 {
        // 统计每个逗号位置对答案的贡献：
        // 从右往左第 1 个逗号出现在 >= 1000 的数中，共 n - 1000 + 1 个；
        // 第 2 个逗号出现在 >= 10^6 的数中，共 n - 10^6 + 1 个；
        // 依此类推，直到 10^p > n 为止。
        let mut total = 0;
        let mut p = 1000;
        while p <= n {
            total += n - p + 1;
            p *= 1000;
        }
        total
    }
}
```
