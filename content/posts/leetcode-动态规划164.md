## 统计移除零后不同整数的数目

给你一个 正 整数 n。

对于从 1 到 n 的每个整数 x，我们记下通过移除 x 的十进制表示中的所有零而得到的整数。

返回一个整数，表示记下的 不同 整数的数量。


```
impl Solution {
    pub fn count_distinct(n: i64) -> i64 {
        // 思路：把 [1, n] 的每个数去掉所有 0 后得到新数，统计不同新数的个数。
        // 可以按"无零数"的位数分组：长度为 L 的无零数共有 9^L 个（每位 1~9）。
        // 对于每个无零数 m，所有"插入若干 0"后得到的数 y 都映射到同一个 m。
        // 这些 y 中，最短的是 m 本身（长度 L），最长的取决于 n 的位数。
        //
        // 经典做法：从高位到低位扫描 n，逐位计算贡献。
        let mut ans: i64 = 0;
        let mut pow9: i64 = 1; // 9^pos
        let mut m = n;

        while m > 0 {
            let d = m % 10;
            if d == 0 {
                // 当前位为 0：说明这一位及以上都无法构造有效前缀，重置贡献
                ans = 0;
            } else {
                // 比当前位小的可选数字：1..=d-1，共 d-1 个（最低位则 d 个）
                let cnt = if pow9 > 1 { d - 1 } else { d };
                ans += cnt * pow9;
            }
            pow9 *= 9;
            m /= 10;
        }

        // 加上所有位数更短的无零数：长度为 1..=(len(n)-1) 的无零数总数
        // 即 9 + 9^2 + ... + 9^(len-1) = (9^len - 9) / 8
        ans + (pow9 - 9) / 8
    }
}
```
