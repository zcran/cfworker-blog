## 只出现一次的数字 II

给你一个整数数组 nums ，除某个元素仅出现 一次 外，其余每个元素都恰出现 三次 。请你找出并返回那个只出现了一次的元素。

你必须设计并实现线性时间复杂度的算法且使用常数级空间来解决此问题。


```
impl Solution {
    /// 位运算思路：
    /// 对每个二进制位统计所有元素在该位上 1 的个数。
    /// 由于除目标元素外，其余元素都恰好出现 3 次，
    /// 因此每位上 1 的总数对 3 取模，剩下的就是目标元素该位的值。
    ///
    /// 时间复杂度 O(32 * n) = O(n)，空间复杂度 O(1)。
    pub fn single_number(nums: Vec<i32>) -> i32 {
        let mut ans = 0;

        for i in 0..32 {
            // 统计当前第 i 位上 1 的个数
            let cnt = nums.iter().map(|&x| (x >> i) & 1).sum::<i32>();
            // 对 3 取模后即为目标元素该位的值
            ans |= (cnt % 3) << i;
        }

        ans
    }
}
```
