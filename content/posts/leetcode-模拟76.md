## 二进制字符串重新安排顺序需要的时间

给你一个二进制字符串 s 。在一秒之中，所有 子字符串 "01" 同时 被替换成 "10" 。这个过程持续进行到没有 "01" 存在。

请你返回完成这个过程所需要的秒数。


```
impl Solution {
    /// 每秒所有 "01" 同时变成 "10"，求变成全 "1...0..." 所需秒数。
    ///
    /// 关键洞察：每个 '1' 需要向左越过前面所有的 '0'。
    /// 但连续的 '1' 会形成阻塞链——后面的 '1' 必须等前面的 '1'
    /// 先移过去才能开始移动。
    ///
    /// 遍历字符串，zeros 记录当前位置之前 '0' 的总数。
    /// 遇到 '1' 且 zeros > 0 时，该 '1' 至少需要 zeros 秒越过所有 '0'；
    /// 但如果前一个 '1' 的完成时间 ans 已经大于等于 zeros，
    /// 则当前 '1' 被阻塞，耗时为 ans + 1。
    pub fn seconds_to_remove_occurrences(s: String) -> i32 {
        let mut zeros = 0;  // 当前位置之前所有 '0' 的累积个数
        let mut ans = 0;    // 上一个需要移动的 '1' 的完成时间

        for ch in s.bytes() {
            if ch == b'0' {
                zeros += 1;
            } else if zeros > 0 {
                // 当前 '1' 的完成时间 = max(被阻塞时间, 越过所有 0 的时间)
                ans = (ans + 1).max(zeros);
            }
        }

        ans
    }
}
```
