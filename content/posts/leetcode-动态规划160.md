## 稳定子序列的数量

给你一个整数数组 nums。

如果一个 子序列 中 不存在连续三个 元素奇偶性相同（仅考虑该子序列内），则称该子序列为稳定子序列 。

请返回所有稳定子序列的数量。

由于结果可能非常大，请将答案对 10^9 + 7 取余数后返回。

子序列 是一个从数组中通过删除某些元素（或不删除任何元素），并保持剩余元素相对顺序不变的 非空 数组。


```
impl Solution {
    pub fn count_stable_subsequences(nums: Vec<i32>) -> i32 {
        const MOD: i64 = 1_000_000_007;

        // f[p][c]：
        //   p 为子序列末尾元素的奇偶性（0 偶 / 1 奇）
        //   c 为子序列末尾连续相同奇偶性的元素个数（1 或 2，最多 2 个）
        let mut f = [[0i64; 2]; 2];

        for x in nums {
            let x = (x & 1) as usize; // 当前元素奇偶性
            let y = x ^ 1;            // 相反奇偶性

            // 把 x 追加到末尾为 y（相反奇偶性）的子序列后，连续长度重置为 1
            f[x][1] = (f[x][1] + f[x][0]) % MOD;

            // 构造末尾为 x、连续长度为 1 的新子序列：
            //   - 接在末尾为 y 的子序列之后（长度 1 或 2 都合法）
            //   - 或者单独作为长度为 1 的子序列（+1）
            f[x][0] = (f[x][0] + f[y][0] + f[y][1] + 1) % MOD;
        }

        let ans = f[0][0] + f[0][1] + f[1][0] + f[1][1];
        (ans % MOD) as i32
    }
}
```
