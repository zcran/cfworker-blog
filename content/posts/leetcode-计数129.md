## 移动后的最大曼哈顿距离

给你一个由字符 'U'、'D'、'L'、'R' 和 '_' 组成的字符串 moves。

从原点 (0, 0) 出发，每个字符表示二维平面上的一次移动：

'U'：向上移动 1 个单位。
'D'：向下移动 1 个单位。
'L'：向左移动 1 个单位。
'R'：向右移动 1 个单位。
'_'：可以独立地替换为 'U'、'D'、'L' 或 'R' 中的任意一个字符。

返回执行完所有移动后，能够达到的距离原点的 最大曼哈顿距离 。

两点 (x1, y1) 和 (x2, y2) 之间的 曼哈顿距离 为 |x1 - x2| + |y1 - y2|。


```
impl Solution {
    /// 计算执行所有移动后能达到的最大曼哈顿距离。
    ///
    /// 策略：统计固定方向的移动后，所有 '_' 都可以用来朝同一方向移动，
    /// 因此最大距离 = |x| + |y| + free（free 为 '_' 的数量）。
    pub fn max_distance(moves: String) -> i32 {
        let (mut x, mut y, mut free) = (0i32, 0i32, 0i32);

        for ch in moves.bytes() {
            match ch {
                b'L' => x -= 1,
                b'R' => x += 1,
                b'D' => y -= 1,
                b'U' => y += 1,
                _    => free += 1,   // '_' 或其他字符（按题意只有 '_'）
            }
        }

        x.abs() + y.abs() + free
    }
}
```
