## 统计移除递增子数组的数目 II

给你一个下标从 0 开始的 正 整数数组 nums 。

如果 nums 的一个子数组满足：移除这个子数组后剩余元素 严格递增 ，那么我们称这个子数组为 移除递增 子数组。比方说，[5, 3, 4, 6, 7] 中的 [3, 4] 是一个移除递增子数组，因为移除该子数组后，[5, 3, 4, 6, 7] 变为 [5, 6, 7] ，是严格递增的。

请你返回 nums 中 移除递增 子数组的总数目。

注意 ，剩余元素为空的数组也视为是递增的。

子数组 指的是一个数组中一段连续的元素序列。


```
impl Solution {
    /// 统计所有「移除递增子数组」的数量。
    ///
    /// 移除递增子数组：删除该连续子数组后，剩余元素严格递增（空数组也算递增）。
    ///
    /// 思路：
    /// 1. 先求出从左端起最长严格递增前缀的长度 l（即 nums[0..=l] 严格递增）。
    ///    如果整个数组已经严格递增，则任意子数组都合法，答案为 n*(n+1)/2。
    /// 2. 从右往左枚举被移除子数组的右端点 r，同时维护右侧严格递增后缀。
    ///    对每个 r，缩小左指针 l，使 nums[l] < nums[r]（保证前后缀拼接后仍严格递增）。
    ///    此时左端点可以是 0..=l 中任意位置，对应 l+2 种选择。
    ///
    /// 时间复杂度 O(n)，空间复杂度 O(1)。
    pub fn incremovable_subarray_count(nums: Vec<i32>) -> i64 {
        let n = nums.len();
        let mut l = 0;

        // 求最长严格递增前缀，l 为递增前缀的最后一个下标
        while l + 1 < n && nums[l] < nums[l + 1] {
            l += 1;
        }

        // 整个数组已严格递增：任意子数组都可移除
        if l == n - 1 {
            return n as i64 * (n as i64 + 1) / 2;
        }

        // 枚举右端点 r，维护右侧严格递增后缀
        let mut ans = l as i64 + 2; // r = n - 1 时，左端点有 l+2 种选择
        for r in (1..n).rev() {
            // 若右侧后缀被破坏，停止扩展
            if r < n - 1 && nums[r] >= nums[r + 1] {
                break;
            }

            // 缩小 l，使得 nums[l] < nums[r]，保证拼接后严格递增
            while l as i32 >= 0 && nums[l] >= nums[r] {
                l -= 1;
            }

            ans += l as i64 + 2;
        }

        ans
    }
}
```
