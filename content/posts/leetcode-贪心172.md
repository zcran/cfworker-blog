## 使数组非递减需要的最小累计值

给你一个长度为 n 的整数数组 nums。

一次操作中，你可以选择任意一个 子数组 nums[l..r]，并将该 子数组 中的每个元素都增加 x，其中 x 可以是任意正整数。

返回使数组变为 非递减 所需的所有操作中，所选 x 的值之和可能达到的 最小值。

如果对于所有 0 <= i < n - 1，都有 nums[i] <= nums[i + 1]，则称数组是 非递减 的。

子数组 是数组中一个连续、 非空 的元素序列。


```
impl Solution {
    pub fn min_operations(nums: Vec<i32>) -> i64 {
        // 每次操作选一个子数组整体加 x（x 为正整数），并把 x 计入代价。
        // 对每个"下降对" nums[i] > nums[i+1]，至少需要补足差值 nums[i] - nums[i+1]。
        // 由于可以对 nums[i] 及其之前的后缀统一加值，这些差值可以合并处理，
        // 最终最小代价就是所有下降差值之和。
        nums.windows(2)
            .map(|w| (w[0] - w[1]).max(0) as i64)
            .sum()
    }
}
```
