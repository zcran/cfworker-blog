## 二叉树灯饰

「力扣嘉年华」的中心广场放置了一个巨型的二叉树形状的装饰树。每个节点上均有一盏灯和三个开关。节点值为 0 表示灯处于「关闭」状态，节点值为 1 表示灯处于「开启」状态。每个节点上的三个开关各自功能如下：

开关 1：切换当前节点的灯的状态；
开关 2：切换 以当前节点为根 的子树中，所有节点上的灯的状态，；
开关 3：切换 当前节点及其左右子节点（若存在的话） 上的灯的状态；

给定该装饰的初始状态 root，请返回最少需要操作多少次开关，可以关闭所有节点的灯。


```
use std::cell::RefCell;
use std::rc::Rc;

// TreeNode 已由 LeetCode 框架在外部定义，此处不再重复

impl Solution {
    /// 关闭所有节点的灯所需的最少开关操作次数。
    ///
    /// 每个节点有 3 个开关：
    /// - 开关 1：切换当前节点
    /// - 开关 2：切换以当前节点为根的整棵子树
    /// - 开关 3：切换当前节点及其左右子节点
    ///
    /// 对每棵子树，DFS 返回 4 个状态，表示在当前子树内部操作后，
    /// 子树中除根节点外的所有节点都已关闭，根节点处于不同"覆盖状态"下的最小代价：
    ///
    /// - `x`：根节点被祖先翻转 **0** 次（模 2 意义下），最终状态 = 初始值 `v`
    /// - `y`：根节点被祖先翻转 **1** 次，最终状态 = `1 - v`
    /// - `z`：根节点被祖先翻转 **1** 次（来源为祖先的开关 2），最终状态 = `1 - v`
    /// - `k`：根节点被祖先翻转 **2** 次（等效 0 次），最终状态 = `v`
    ///
    /// 区分 `y` 与 `z` 是因为开关 2 会波及孙节点，而开关 3 只影响直接子节点，
    /// 二者对下一层子树的传递信息不同。
    pub fn close_lamp_in_tree(root: Option<Rc<RefCell<TreeNode>>>) -> i32 {
        let (x, y, z, k) = Self::dfs(&root);
        // 根节点没有父节点，因此"祖先操作"必须由根节点自己模拟：
        // - x：无需模拟祖先操作，直接取代价
        // - y：模拟父节点按开关 3，代价 +1
        // - z：模拟父节点按开关 2，代价 +1
        // - k：模拟父节点同时按开关 2 和 3，代价 +2
        x.min(y + 1).min(z + 1).min(k + 2)
    }

    fn dfs(node: &Option<Rc<RefCell<TreeNode>>>) -> (i32, i32, i32, i32) {
        let Some(n) = node else {
            // 空子树无需任何操作，四状态代价均为 0
            return (0, 0, 0, 0);
        };
        let n = n.borrow();
        let v = n.val;

        let (la, lb, lc, ld) = Self::dfs(&n.left);
        let (ra, rb, rc, rd) = Self::dfs(&n.right);

        let sum_x = la + ra; // 子节点均处于"翻转 0 次"状态
        let sum_y = lb + rb; // 子节点均处于"翻转 1 次（开关 3）"状态
        let sum_z = lc + rc; // 子节点均处于"翻转 1 次（开关 2）"状态
        let sum_k = ld + rd; // 子节点均处于"翻转 2 次"状态

        // 当前节点的 4 种状态，枚举当前节点按哪些开关（与祖先操作叠加）
        //
        // 状态 x：根节点最终需为 0（关闭），且翻转次数为偶数（状态 = v）
        // 选项：不按 / 按开关 3 / 按开关 2 / 按开关 2+3
        let x = [
            sum_x + if v == 1 { 1 } else { 0 }, // 不按：v=1 需按开关 1
            sum_y + if v == 1 { 1 } else { 2 }, // 按开关 3：当前翻转 1 次
            sum_z + if v == 1 { 1 } else { 2 }, // 按开关 2：当前翻转 1 次
            sum_k + if v == 1 { 3 } else { 2 }, // 按开关 2+3：当前翻转 2 次=0，需额外关闭
        ]
        .into_iter()
        .min()
        .unwrap();

        // 状态 y：根节点最终需为 1（开启，供父节点后续关闭），翻转次数为奇数
        let y = [
            sum_x + if v == 1 { 0 } else { 1 }, // 不按：v=1 已处于 1
            sum_y + if v == 1 { 2 } else { 1 }, // 按开关 3：翻转 2 次=0，需再处理
            sum_z + if v == 1 { 2 } else { 1 }, // 按开关 2
            sum_k + if v == 1 { 2 } else { 3 }, // 按开关 2+3：翻转 3 次=1
        ]
        .into_iter()
        .min()
        .unwrap();

        // 状态 z：根节点最终需为 0，但子节点受到祖先开关 2 的波及
        let z = [
            sum_x + if v == 1 { 2 } else { 1 },
            sum_y + if v == 1 { 2 } else { 3 },
            sum_z + if v == 1 { 0 } else { 1 },
            sum_k + if v == 1 { 2 } else { 1 },
        ]
        .into_iter()
        .min()
        .unwrap();

        // 状态 k：根节点最终需为 1，且子节点受到祖先开关 2+3 的波及
        let k = [
            sum_x + if v == 1 { 1 } else { 2 },
            sum_y + if v == 1 { 3 } else { 2 },
            sum_z + if v == 1 { 1 } else { 0 },
            sum_k + if v == 1 { 1 } else { 2 },
        ]
        .into_iter()
        .min()
        .unwrap();

        (x, y, z, k)
    }
}
```
