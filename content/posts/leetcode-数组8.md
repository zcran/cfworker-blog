## 1 比特与 2 比特字符

有两种特殊字符：

第一种字符可以用一比特 0 表示
第二种字符可以用两比特（10 或 11）表示

给你一个以 0 结尾的二进制数组 bits ，如果最后一个字符必须是一个一比特字符，则返回 true 。




```
impl Solution {
    /// 判断最后一个字符是否必须是一比特字符。
    ///
    /// 从头按规则解码：
    /// - `bits[i] == 0`：一比特字符，前进 1 步；
    /// - `bits[i] == 1`：两比特字符，前进 2 步。
    /// 若最终恰好停在最后一位，说明最后一位是一比特字符。
    ///
    /// 时间复杂度 O(n)，空间复杂度 O(1)。
    pub fn is_one_bit_character(bits: Vec<i32>) -> bool {
        let n = bits.len();
        let mut i = 0;

        // 走到倒数第二位之前，按规则跳跃
        while i < n - 1 {
            i += if bits[i] == 1 { 2 } else { 1 };
        }

        i == n - 1
    }
}
```
