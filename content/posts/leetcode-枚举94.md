## 统计单比特整数

给你一个整数 n。

如果一个整数的二进制表示中所有位都相同，则称其为 单比特数（Monobit）。

返回范围[0, n]（包括两端）内 单比特数 的个数。




```
impl Solution {
    pub fn count_monobit(n: i32) -> i32 {
        // 单比特数 = 0, 1, 3, 7, 15, 31, ... (0 和 2^k - 1)
        // 即 0 以及所有全1的二进制数
        // 范围 [0, n] 中最大的单比特数是 (2^⌊log2(n+1)⌋ - 1)
        // 但 0 也算一个，所以答案是 floor(log2(n+1)) + 1

        if n < 0 {
            return 0;
        }

        // ilog2() 返回 u32，需要转换为 i32
        // 由于 n <= 2^31 - 1，n+1 <= 2^31，ilog2 最大为 31，安全转换
        ((n + 1).ilog2() + 1) as i32
    }
}
```
