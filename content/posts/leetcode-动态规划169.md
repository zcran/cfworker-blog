## 拆分到 1 的最小总代价

给你一个整数 n。

在一次操作中，你可以将整数 x 拆分为两个正整数 a 和 b，使得 a + b = x。

此操作的代价是 a * b。

返回将整数 n 拆分为 n 个 1 所需的最小总代价。


```
impl Solution {
    pub fn min_cost(n: i32) -> i32 {
        // 每次拆分 a + b = x 的代价为 a * b。
        // 最优策略是每次拆出一个 1：x = (x-1) + 1，代价为 x-1。
        // 总代价 = (n-1) + (n-2) + ... + 1 = n*(n-1)/2。
        // 使用 i64 防止中间乘法溢出。
        (n as i64 * (n - 1) as i64 / 2) as i32
    }
}
```
