## 交替位二进制数

给定一个正整数，检查它的二进制表示是否总是 0、1 交替出现：换句话说，就是二进制表示中相邻两位的数字永不相同。


```
impl Solution {
    /// 核心思路：
    /// 设 x = n ^ (n >> 1)。
    /// 若 n 的二进制相邻位始终交替，则每对相邻位都不同，
    /// 因此 x 的每一位（除最高位对应 n 的最高位外）都应为 1，
    /// 即 x 的二进制形如 0...0111...1（全 1 后缀）。
    ///
    /// 全 1 后缀的性质：x & (x + 1) == 0。
    pub fn has_alternating_bits(n: i32) -> bool {
        let x = (n >> 1) ^ n;
        x & (x + 1) == 0
    }
}
```
