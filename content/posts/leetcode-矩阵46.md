## 检查是否有合法括号字符串路径

一个括号字符串是一个 非空 且只包含 '(' 和 ')' 的字符串。如果下面 任意 条件为 真 ，那么这个括号字符串就是 合法的 。

字符串是 () 。
字符串可以表示为 AB（A 连接 B），A 和 B 都是合法括号序列。
字符串可以表示为 (A) ，其中 A 是合法括号序列。

给你一个 m x n 的括号网格图矩阵 grid 。网格图中一个 合法括号路径 是满足以下所有条件的一条路径：

路径开始于左上角格子 (0, 0) 。
路径结束于右下角格子 (m - 1, n - 1) 。
路径每次只会向 下 或者向 右 移动。
路径经过的格子组成的括号字符串是 合法 的。

如果网格图中存在一条 合法括号路径 ，请返回 true ，否则返回 false 。


```
impl Solution {
    /// 状态用 u128 位集表示：第 b 位为 1 ⇔ 存在一条到达该格的路径，其括号前缀平衡值为 b。
    ///
    /// 转移：
    ///   吃 '(' → 平衡 +1 → 位集左移 1；
    ///   吃 ')' → 平衡 -1 → 位集右移 1（最低位移出即丢弃，等价于"平衡 0 时不能再吃 ')'"）。
    /// 每格的可达位集 = (左邻位集 | 上邻位集) 再做一次字符转移。
    ///
    /// 高位安全性：路径最长 m+n-1 ≤ 199。u128 只能表示平衡 0..=127，
    /// 左移溢出丢弃的是平衡 ≥ 128 的状态——它们要回到 0 至少还需 128 步，
    /// 而总步数 < 200，故这些状态不可能出现在终点的平衡 0 上，丢弃安全。
    ///
    /// 时间复杂度 O(m*n)，空间 O(n)。
    pub fn has_valid_path(grid: Vec<Vec<char>>) -> bool {
        let m = grid.len();
        let n = grid[0].len();

        // 起点必须 '('，终点必须 ')'，否则前缀/后缀立刻非法
        if grid[0][0] != '(' || grid[m - 1][n - 1] != ')' {
            return false;
        }

        // prev[j]：上一行第 j 列的可达平衡位集；初始化为全 0
        let mut prev_row = vec![0u128; n];

        for i in 0..m {
            let mut cur_row = vec![0u128; n];
            for j in 0..n {
                // 起点：已吃掉 '('，平衡为 1
                if i == 0 && j == 0 {
                    cur_row[0] = 1u128 << 1;
                    continue;
                }

                // 汇集左、上两个来源的可达位集
                let mut mask = 0u128;
                if j > 0 {
                    mask |= cur_row[j - 1];
                }
                if i > 0 {
                    mask |= prev_row[j];
                }

                // 吃掉当前格的括号：'(' 左移，')' 右移
                cur_row[j] = if grid[i][j] == '(' {
                    mask << 1
                } else {
                    mask >> 1
                };
            }
            prev_row = cur_row;
        }

        // 终点平衡必须恰为 0（第 0 位为 1）
        prev_row[n - 1] & 1 == 1
    }
}
```
