## 合并相邻且相等的元素

给你一个整数数组 nums。

你需要 重复 执行以下合并操作，直到无法再进行任何更改：

如果数组中存在 两个相邻且相等的元素，选择当前数组中 最左侧 的这对相邻元素，并用它们的 和 替换它们。

每次合并操作后，数组的大小 减少 1。对更新后的数组重复此过程，直到无法再进行任何操作。

返回完成所有可能的合并操作后的最终数组。


```
impl Solution {
    /// 返回执行所有相邻相等合并操作后的最终数组
    ///
    /// # 算法思路
    /// 使用栈模拟合并过程：
    /// 1. 依次将每个元素压入栈
    /// 2. 每次压入后，检查栈顶两个元素是否相等
    /// 3. 如果相等，弹出栈顶，将新的栈顶值乘以 2（合并）
    /// 4. 重复检查，直到栈顶两个元素不相等为止
    ///
    /// # 复杂度
    /// - 时间复杂度：O(n)，每个元素最多入栈出栈一次
    /// - 空间复杂度：O(n)，栈空间
    pub fn merge_adjacent(nums: Vec<i32>) -> Vec<i64> {
        let mut stack: Vec<i64> = Vec::with_capacity(nums.len());

        for &x in &nums {
            // 将当前元素压入栈
            stack.push(x as i64);

            // 循环检查栈顶两个元素是否相等
            while stack.len() >= 2 && stack[stack.len() - 1] == stack[stack.len() - 2] {
                // 弹出栈顶元素（与栈顶下方元素相等）
                stack.pop();
                // 将新的栈顶元素乘以 2（合并）
                let last = stack.len() - 1;
                stack[last] *= 2;
            }
        }

        stack
    }
}
```
