## 划分数组的最少相邻交换次数

给你一个整数数组 nums 和两个整数 a 和 b，满足 a < b。

如果一个数组可以按顺序分成三个 连续 的部分，并且满足以下条件，则称其为 好数组：

第一部分中的每个元素都 小于 a。
第二部分中的每个元素都 在 闭区间 [a, b] 内。
第三部分中的每个元素都 大于 b。

这三个部分中的任意一个都 可以 为空。

在一次 相邻交换 中，你可以交换 nums 的两个 相邻 元素。

返回使 nums 成为好数组所需的 最少 相邻交换次数。由于答案可能非常大，请将其对 10^9 + 7 取余 后返回。


```
impl Solution {
    pub fn min_adjacent_swaps(nums: Vec<i32>, a: i32, b: i32) -> i32 {
        // 把元素按目标归属映射为类别：0 = 第一组(< a)，1 = 第二组([a,b])，2 = 第三组(> b)。
        // 好数组要求类别单调不降（0...0 1...1 2...2）。
        // 最少相邻交换次数 = 逆序对数量，即统计每个元素前面有多少个"应排在它之后"的元素。
        // 扫描时维护已出现的 0 的个数 cnt0 和 1 的个数 cnt1：
        //   - 遇到 0：前面所有的 1 和 2 都要与它交换，代价 = cnt1 + cnt2
        //   - 遇到 1：前面所有的 2 要交换，代价 = cnt2
        //   - 遇到 2：无需交换
        const MOD: i64 = 1_000_000_007;

        let mut ans = 0i64;
        let mut cnt0 = 0i64;
        let mut cnt1 = 0i64;
        let mut cnt2 = 0i64;

        for x in nums {
            if x < a {
                ans += cnt1 + cnt2;
                cnt0 += 1;
            } else if x <= b {
                ans += cnt2;
                cnt1 += 1;
            } else {
                cnt2 += 1;
            }
        }

        (ans % MOD) as i32
    }
}
```
