## 魔塔游戏

小扣当前位于魔塔游戏第一层，共有 N 个房间，编号为 0 ~ N-1。每个房间的补血道具/怪物对于血量影响记于数组 nums，其中正数表示道具补血数值，即血量增加对应数值；负数表示怪物造成伤害值，即血量减少对应数值；0 表示房间对血量无影响。

小扣初始血量为 1，且无上限。假定小扣原计划按房间编号升序访问所有房间补血/打怪，为保证血量始终为正值，小扣需对房间访问顺序进行调整，每次仅能将一个怪物房间（负数的房间）调整至访问顺序末尾。请返回小扣最少需要调整几次，才能顺利访问所有房间。若调整顺序也无法访问完全部房间，请返回 -1。


```
use std::collections::BinaryHeap;

impl Solution {
    /// 返回最少需要将多少个怪物房间（负数）移至末尾，使血量始终为正。
    /// 若总和 < 0，则无论如何调整都无法存活，返回 -1。
    ///
    /// 核心思想：贪心 + 反悔堆。
    /// 按顺序遍历房间，用最大堆记录已遇到的怪物伤害。
    /// 当血量跌破 1 时，从已访问的怪物中"反悔"移除伤害最大的那个
    ///（即把它移到序列末尾），这样能以最小代价恢复血量。
    pub fn magic_tower(nums: Vec<i32>) -> i32 {
        // 总血量为负则必死
        if nums.iter().map(|&x| x as i64).sum::<i64>() < 0 {
            return -1;
        }

        let mut hp = 1i64;      // 当前血量
        let mut moved = 0;      // 已移至末尾的怪物数
        let mut monsters = BinaryHeap::new(); // 最大堆，存已遇到的怪物伤害（正数）

        for &x in &nums {
            let val = x as i64;

            if x < 0 {
                // 记录这个怪物，后续可能需要反悔移除
                monsters.push(-val); // 存正数，方便最大堆取最大伤害
            }

            hp += val;

            // 血量不足，从已访问的怪物中移除伤害最大的（移到末尾）
            if hp < 1 {
                // 此时 x 必为负数，堆非空，且堆顶 >= -x
                hp += monsters.pop().unwrap();
                moved += 1;
            }
        }

        moved
    }
}
```
