## 一次替换后的三元素最大乘积

给你一个整数数组 nums。

你 必须 将数组中的 恰好一个 元素替换为范围 [-105, 105]（包含边界）内的 任意 整数。

在进行这一替换操作后，请确定从修改后的数组中选择 任意三个互不相同的下标 对应的元素所能得到的 最大乘积 。

返回一个整数，表示可以达到的 最大乘积 。


```
impl Solution {
    pub fn max_product(nums: Vec<i32>) -> i64 {
        // 替换一个元素后要最大化三个数之积。
        // 最优策略：把某个元素替换为 1e5（最大值），其余两个取原数组中绝对值最大的两个数，
        // 这样三数同号，乘积为正且最大。
        // 因此只需在原数组里找绝对值最大的两个数，答案 = 1e5 * |mx1| * |mx2|。
        let (mut mx1, mut mx2) = (0i64, 0i64); // 最大、次大绝对值

        for x in nums {
            let a = (x as i64).abs();
            if a > mx1 {
                mx2 = mx1;
                mx1 = a;
            } else if a > mx2 {
                mx2 = a;
            }
        }

        100_000 * mx1 * mx2
    }
}
```
