## 图中边值的最大和

给你一个包含 n 个节点的 无向连通图，节点按从 0 到 n - 1 编号。每个节点 最多 与其他两个节点相连。

图中包含 m 条边，使用一个二维数组 edges 表示，其中 edges[i] = [ai, bi] 表示节点 ai 和节点 bi 之间有一条边。

你需要为每个节点分配一个从 1 到 n 的 唯一 值。边的值定义为其两端节点值的 乘积 。

你的得分是图中所有边值的总和。

返回你可以获得的 最大 得分。


```
impl Solution {
    /// 计算无向连通图（每个节点度数 ≤ 2）的最大得分
    ///
    /// 图的每个节点度数最多为 2，因此图由若干条路径和至多一个环组成。
    /// 为了最大化所有边两端节点值乘积的总和，应让较大的节点值尽量靠近排列。
    ///
    /// # 参数
    /// - `n`: 节点数量
    /// - `edges`: 边列表，每条边 [a, b] 表示节点 a 和 b 相连
    ///
    /// # 返回
    /// 最大可能的得分
    pub fn max_score(n: i32, edges: Vec<Vec<i32>>) -> i64 {
        let n = n as i64;
        let m = edges.len() as i64;

        // 基础公式：对于一条路径（或树），最大得分公式为：
        // sum_{i=1}^{n-1} i * (i+1) = n(n-1)(n+1)/3
        // 即 (n^3 - n) / 3
        // 等价于 (2n^3 + 3n^2 - 5n) / 6
        // 但为了与 C++ 版本一致，使用 (n*n*2 + n*5 - 6) * (n-1) / 6
        let base = (2 * n * n + 5 * n - 6) * (n - 1) / 6;

        // 如果边数等于节点数，说明存在一个环（因为连通且每个节点度 ≤ 2）
        // 环结构比路径能获得额外 2 分
        if m == n {
            base + 2
        } else {
            base
        }
    }
}
```
