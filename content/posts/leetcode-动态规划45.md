## 多米诺和托米诺平铺

有两种形状的瓷砖：一种是 2 x 1 的多米诺形，另一种是形如 "L" 的托米诺形。两种形状都可以旋转。

🄾🄾     和         🄾🄾
                   🄾

给定整数 n ，返回可以平铺 2 x n 的面板的方法的数量。返回对 10^9 + 7 取模 的值。

平铺指的是每个正方形都必须有瓷砖覆盖。两个平铺不同，当且仅当面板上有四个方向上的相邻单元中的两个，使得恰好有一个平铺有一个瓷砖占据两个正方形。


```
impl Solution {
    /// 790. 多米诺和托米诺平铺
    ///
    /// 2×n 面板的平铺，按"当前列被填充的状态"做 DP：
    ///   状态 0：当前列上下都空
    ///   状态 1：当前列上一格已填、下一格空
    ///   状态 2：当前列下一格已填、上一格空
    ///   状态 3：当前列上下都满（需要向下一列伸出/补齐）
    ///
    /// 转移（每前进一列）：
    ///   g0 = f0 + f1 + f2 + f3   用竖多米诺 / 两个托米诺 / 补齐空缺
    ///   g1 = f2 + f3             由下一行空缺状态补一个托米诺
    ///   g2 = f1 + f3
    ///   g3 = f0                  用两个横多米诺铺满并推进到下一列
    ///
    /// 初始 f = [1, 0, 0, 0]，迭代 n 列后返回 f0。
    pub fn num_tilings(n: i32) -> i32 {
        const MOD: i64 = 1_000_000_007;
        let mut f = [1i64, 0, 0, 0];
        for _ in 0..n {
            let g = [
                (f[0] + f[1] + f[2] + f[3]) % MOD,
                (f[2] + f[3]) % MOD,
                (f[1] + f[3]) % MOD,
                f[0],
            ];
            f = g;
        }
        f[0] as i32
    }
}
```
