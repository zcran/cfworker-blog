## 找到冠军 I

一场比赛中共有 n 支队伍，按从 0 到  n - 1 编号。

给你一个下标从 0 开始、大小为 n * n 的二维布尔矩阵 grid 。对于满足 0 <= i, j <= n - 1 且 i != j 的所有 i, j ：如果 grid[i][j] == 1，那么 i 队比 j 队 强 ；否则，j 队比 i 队 强 。

在这场比赛中，如果不存在某支强于 a 队的队伍，则认为 a 队将会是 冠军 。

返回这场比赛中将会成为冠军的队伍。


```
impl Solution {
    /// 冠军 = 没有队伍强于它的队，即它强于所有其他队。
    /// 在 n×n 布尔矩阵中，第 i 行除对角外全为 1 ⇔ i 队战胜其余 n-1 队。
    /// 因此找到行和为 n-1 的行即可（对角线 grid[i][i] 恒为 0）。
    ///
    /// 进一步优化：只需检查第 i 行第 0 列——若 grid[i][0] == 1（i≠0），说明 i 强于 0，
    /// 则 0 不可能夺冠；一旦发现某行首列为 0，该行即为冠军候选。
    /// 但最简且易读的写法仍是找行和为 n-1 的行。
    pub fn find_champion(grid: Vec<Vec<i32>>) -> i32 {
        let n = grid.len();
        // 找行和为 n-1 的行（即该队战胜所有其他队）
        (0..n)
            .find(|&i| grid[i].iter().sum::<i32>() == n as i32 - 1)
            .map_or(-1, |i| i as i32)
    }
}
```
