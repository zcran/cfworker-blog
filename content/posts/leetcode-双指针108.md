## 区分黑球与白球

桌子上有 n 个球，每个球的颜色不是黑色，就是白色。

给你一个长度为 n 、下标从 0 开始的二进制字符串 s，其中 1 和 0 分别代表黑色和白色的球。

在每一步中，你可以选择两个相邻的球并交换它们。

返回「将所有黑色球都移到右侧，所有白色球都移到左侧所需的 最小步数」。


```
impl Solution {
    /// 将所有黑色球（'1'）移到右侧、白色球（'0'）移到左侧的最小相邻交换次数。
    ///
    /// 思路：从左到右扫描，遇到 '1' 就累加计数 sum（表示当前还未被交换到右侧的黑球数）；
    /// 遇到 '0' 时，它需要越过前面所有未归位的 '1'，因此累加 sum 到答案。
    /// 时间复杂度 O(n)，空间复杂度 O(1)。
    pub fn minimum_steps(s: String) -> i64 {
        let mut ans = 0i64;
        let mut sum = 0i64;

        for b in s.bytes() {
            if b == b'1' {
                sum += 1;
            } else {
                ans += sum;
            }
        }

        ans
    }
}
```
