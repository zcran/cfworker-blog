## 输入单词需要的最少按键次数 II

给你一个字符串 word，由小写英文字母组成。

电话键盘上的按键与 不同 小写英文字母集合相映射，可以通过按压按键来组成单词。例如，按键 2 对应 ["a","b","c"]，我们需要按一次键来输入 "a"，按两次键来输入 "b"，按三次键来输入 "c"。

现在允许你将编号为 2 到 9 的按键重新映射到 不同 字母集合。每个按键可以映射到 任意数量 的字母，但每个字母 必须 恰好 映射到 一个 按键上。你需要找到输入字符串 word 所需的 最少 按键次数。

返回重新映射按键后输入 word 所需的 最少 按键次数。

下面给出了一种电话键盘上字母到按键的映射作为示例。注意 1，*，# 和 0 不 对应任何字母。


```
impl Solution {
    pub fn minimum_pushes(word: String) -> i32 {
        // 统计每个字母出现频率
        let mut freq = [0i32; 26];
        for b in word.bytes() {
            freq[(b - b'a') as usize] += 1;
        }

        // 按频率降序排序（贪心：高频字母分配最少按键次数）
        freq.sort_by(|a, b| b.cmp(a));

        // 8个按键(2-9)，每个按键第1个位置按1次，第2个位置按2次...
        // 排序后：freq[0..7] 按1次，freq[8..15] 按2次，freq[16..23] 按3次，freq[24..25] 按4次
        freq.iter()
            .enumerate()
            .take_while(|&(_, &f)| f > 0)  // 显式解引用，只处理出现过的字母
            .map(|(i, &f)| ((i / 8 + 1) as i32) * f)
            .sum()
    }
}
```
