## 最低票价

在一个火车旅行很受欢迎的国度，你提前一年计划了一些火车旅行。在接下来的一年里，你要旅行的日子将以一个名为 days 的数组给出。每一项是一个从 1 到 365 的整数。

火车票有 三种不同的销售方式 ：

一张 为期一天 的通行证售价为 costs[0] 美元；
一张 为期七天 的通行证售价为 costs[1] 美元；
一张 为期三十天 的通行证售价为 costs[2] 美元。

通行证允许数天无限制的旅行。 例如，如果我们在第 2 天获得一张 为期 7 天 的通行证，那么我们可以连着旅行 7 天：第 2 天、第 3 天、第 4 天、第 5 天、第 6 天、第 7 天和第 8 天。

返回 你想要完成在给定的列表 days 中列出的每一天的旅行所需要的最低消费 。


```
impl Solution {
    /// 983. 最低票价
    ///
    /// dp[d]：覆盖到第 d 天所需的最低消费（只考虑 days 中的旅行日，非旅行日沿用前一天的值）。
    /// 对每个旅行日 d，有三种买票方式：
    ///   买 1 天票：dp[d-1] + costs[0]
    ///   买 7 天票：dp[d-7] + costs[1]（覆盖 [d-6, d]，用 d-7 的状态）
    ///   买 30 天票：dp[d-30] + costs[2]
    /// 取三者最小值。
    ///
    /// 由于 days 严格递增，可以只对 days 中的日期做 DP，用三个指针记录
    /// 上一个超出 7 天 / 30 天窗口的旅行日在 dp 数组中的位置，避免开 365+ 大小数组。
    pub fn mincost_tickets(days: Vec<i32>, costs: Vec<i32>) -> i32 {
        let n = days.len();
        // dp[i]：覆盖前 i 个旅行日的最低消费
        let mut dp = vec![0i32; n + 1];
        // i7 / i30 分别指向 7 天 / 30 天票能覆盖的最早旅行日的前一个位置
        let (mut i7, mut i30) = (0usize, 0usize);

        for i in 1..=n {
            // 单独买 1 天票
            let mut best = dp[i - 1] + costs[0];

            // 7 天票：向前找到第一个满足 days[i-1] - days[j-1] < 7 的 j
            while days[i - 1] - days[i7] >= 7 {
                i7 += 1;
            }
            best = best.min(dp[i7] + costs[1]);

            // 30 天票
            while days[i - 1] - days[i30] >= 30 {
                i30 += 1;
            }
            best = best.min(dp[i30] + costs[2]);

            dp[i] = best;
        }

        dp[n]
    }
}
```
