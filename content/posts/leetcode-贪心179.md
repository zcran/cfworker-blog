## 交替数列的最大元素

给你三个整数 n、s 和 m。

如果一个长度为 n 的整数序列 seq 满足以下条件，则认为它是 有效 的：

· seq[0] = s。
· 序列是 交替 的，这意味着：
    · seq[0] > seq[1] < seq[2] > ...，或者
    · seq[0] < seq[1] > seq[2] < ...。
· 对于每个相邻元素对，|seq[i] - seq[i - 1]| <= m。

长度为 1 的序列被认为是交替的。

返回任何有效序列中可能出现的 最大 元素。


```
impl Solution {
    pub fn maximum_value(n: i32, s: i32, m: i32) -> i64 {
        // 长度为 1 时序列固定为 [s]，最大值即 s
        if n == 1 {
            return s as i64;
        }

        // 交替序列中，峰值出现在下标 1, 3, 5, ...（奇数下标）。
        // 第一个峰值 seq[1] 相对 s 最多上升 m（即 s + m），
        // 之后每个后续峰值因交替约束，相比前一个峰值最多上升 m - 1。
        // 峰值个数为 n / 2，故最大值为：
        //   s + m + (m - 1) * (n / 2 - 1)
        s as i64 + m as i64 + (m as i64 - 1) * (n as i64 / 2 - 1)
    }
}
```
