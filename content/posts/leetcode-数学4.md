## 优美的排列 II

给你两个整数 n 和 k ，请你构造一个答案列表 answer ，该列表应当包含从 1 到 n 的 n 个不同正整数，并同时满足下述条件：

假设该列表是 answer = [aˇ1, aˇ2, aˇ3, ... , aˇn] ，那么列表 [|aˇ1 - aˇ2|, |aˇ2 - aˇ3|, |aˇ3 - aˇ4|, ... , |aˇ(n-1) - aˇn|] 中应该有且仅有 k 个不同整数。

返回列表 answer 。如果存在多种答案，只需返回其中 任意一种 。




```
impl Solution {
    /// 构造一个包含 1..=n 的排列，使其相邻元素差的绝对值恰好有 k 个不同的值。
    ///
    /// 贪心策略：让差的绝对值从 k, k-1, ..., 1 依次出现。
    /// 用双指针维护当前可用的最小值和最大值：
    ///   - 第 0 步取最小值，之后每步交替取最大、最小、最大……使得相邻差依次为
    ///     k, k-1, k-2, ..., 1。
    ///   - 当已经产生 k 个不同差值后，剩余元素按顺序排列（差为 1），不再新增不同值。
    ///
    /// 具体做法：维护 `l`（当前最小可用）和 `r`（当前最大可用）。
    /// 每一步根据 `k` 的奇偶性选择取 `l` 还是 `r`，取完后相应的指针移动，
    /// 并在 `k > 1` 时递减 `k`，直到 `k == 1` 后固定取 `l`（或按原逻辑继续）。
    pub fn construct_array(n: i32, mut k: i32) -> Vec<i32> {
        let mut ans = Vec::with_capacity(n as usize);
        let (mut l, mut r) = (1, n);

        while l <= r {
            if k > 1 {
                // 交替从两端取值，使相邻差依次为 k, k-1, ...
                if k % 2 == 0 {
                    ans.push(r);
                    r -= 1;
                } else {
                    ans.push(l);
                    l += 1;
                }
                k -= 1;
            } else {
                // 差值已全部产生，剩余元素顺序填充
                ans.push(l);
                l += 1;
            }
        }

        ans
    }
}
```
