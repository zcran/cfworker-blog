## 美化数组的最少删除数

给你一个下标从 0 开始的整数数组 nums ，如果满足下述条件，则认为数组 nums 是一个 美丽数组 ：

nums.length 为偶数

对所有满足 i % 2 == 0 的下标 i ，nums[i] != nums[i + 1] 均成立

注意，空数组同样认为是美丽数组。

你可以从 nums 中删除任意数量的元素。当你删除一个元素时，被删除元素右侧的所有元素将会向左移动一个单位以填补空缺，而左侧的元素将会保持 不变 。

返回使 nums 变为美丽数组所需删除的 最少 元素数目。


```
impl Solution {
    /// 返回使数组变为美丽数组所需删除的最少元素数目
    ///
    /// # 美丽数组条件
    /// 1. 长度为偶数
    /// 2. 所有偶数下标 i 满足：nums[i] != nums[i+1]
    ///
    /// # 算法思路
    /// 贪心扫描：从左到右构建美丽数组
    /// - 用 `i` 指向当前要匹配的偶数下标位置
    /// - 若 `nums[i] == nums[i+1]`，必须删除其中一个，计数 +1，`i` 后移一位继续判断
    /// - 若 `nums[i] != nums[i+1]`，这配对成功，保留这两个元素，`i` 后移两位
    /// - 最后若剩余元素个数为奇数，需删除最后一个使总长度为偶数
    pub fn min_deletion(nums: Vec<i32>) -> i32 {
        let n = nums.len();
        let mut deletions = 0;
        let mut i = 0;

        // 每次配对相邻两个元素，判断是否相等
        while i < n - 1 {
            if nums[i] == nums[i + 1] {
                // 相邻相等，必须删除一个（删右侧元素，i 仅前进一位）
                deletions += 1;
                i += 1;
            } else {
                // 相邻不等，配对成功，跳过这两个元素
                i += 2;
            }
        }

        // 修正：如果保留的元素个数为奇数，需额外删除一个
        // 保留元素数 = n - deletions，若为奇数则 +1
        if (n - deletions) % 2 == 1 {
            deletions += 1;
        }

        deletions as i32
    }
}
```
