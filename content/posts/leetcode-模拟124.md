## 字符串的反转度

给你一个字符串 s，计算其 反转度。

反转度的计算方法如下：

1. 对于每个字符，将其在 反转 字母表中的位置（'a' = 26, 'b' = 25, ..., 'z' = 1）与其在字符串中的位置（下标从1 开始）相乘。
2. 将这些乘积加起来，得到字符串中所有字符的和。

返回 反转度。



```
impl Solution {
    /// 计算字符串的反转度
    ///
    /// 反转度定义：
    /// - 每个字符的反转字母表位置：'a' = 26, 'b' = 25, ..., 'z' = 1
    /// - 字符位置从 1 开始计数（即下标 + 1）
    /// - 反转度 = Σ(字符位置 × 反转字母表位置)
    ///
    /// # 参数
    /// - `s`: 输入字符串，仅包含小写字母
    ///
    /// # 返回值
    /// - 字符串的反转度
    pub fn reverse_degree(s: String) -> i32 {
        s.bytes()
            .enumerate()
            .map(|(idx, byte)| {
                let position = (idx + 1) as i32;          // 字符在字符串中的位置（从 1 开始）
                let reverse_alpha = (b'z' - byte + 1) as i32; // 反转字母表位置：'a'=26, 'z'=1
                position * reverse_alpha
            })
            .sum()
    }
}
```
