##  统计道路上的碰撞次数

在一条无限长的公路上有 n 辆汽车正在行驶。汽车按从左到右的顺序按从 0 到 n - 1 编号，每辆车都在一个 独特的 位置。

给你一个下标从 0 开始的字符串 directions ，长度为 n 。directions[i] 可以是 'L'、'R' 或 'S' 分别表示第 i 辆车是向 左 、向 右 或者 停留 在当前位置。每辆车移动时 速度相同 。

碰撞次数可以按下述方式计算：

当两辆移动方向 相反 的车相撞时，碰撞次数加 2 。

当一辆移动的车和一辆静止的车相撞时，碰撞次数加 1 。

碰撞发生后，涉及的车辆将无法继续移动并停留在碰撞位置。除此之外，汽车不能改变它们的状态或移动方向。

返回在这条道路上发生的 碰撞总次数 。


```
impl Solution {
    /// 计算公路上车辆碰撞的总次数
    ///
    /// # 算法思路
    /// 从左到右扫描，使用状态变量 `state` 记录当前连续右行车辆的情况：
    /// - `state = -1`：初始状态，还没有遇到任何车辆
    /// - `state = 0`：左侧已有车辆停止或不存在可碰撞的对象
    /// - `state > 0`：表示当前有 `state` 辆连续向右行驶的车辆
    ///
    /// # 碰撞规则
    /// 1. `L`（左行）：
    ///    - 若 `state > 0`：与所有连续右行车对向碰撞，次数 `state + 1`（为什么？稍后解释）
    ///    - 否则无碰撞
    /// 2. `S`（静止）：
    ///    - 若 `state > 0`：右行车撞上静止车，次数 `state`
    ///    - 否则无碰撞
    /// 3. `R`（右行）：
    ///    - 连续右行车计数增加
    pub fn count_collisions(directions: String) -> i32 {
        let mut total_collisions = 0;
        // 状态变量：-1=初始，0=左侧已停止，>0=连续右行车辆数
        let mut state: i32 = -1;

        for ch in directions.chars() {
            match ch {
                // 处理左行车辆
                'L' => {
                    if state >= 0 {
                        // state > 0 时有对向碰撞，state == 0 时无碰撞
                        // state + 1 的巧妙之处：
                        // - state > 0 时，表示有 state 辆 R 和当前这辆 L 对撞
                        // - state == 0 时，加 1 后不增加碰撞次数（0 + 1，但表达式不成立）
                        total_collisions += state + 1;
                        state = 0; // 碰撞后所有车停止
                    }
                }
                // 处理静止车辆
                'S' => {
                    if state > 0 {
                        // 前方所有右行车撞上这辆静止车
                        total_collisions += state;
                    }
                    state = 0; // 标记左侧已有静止车
                }
                // 处理右行车辆
                'R' => {
                    if state >= 0 {
                        // 已经有车辆在左侧，累计右行计数
                        state += 1;
                    } else {
                        // 初始状态，第一辆车是 R
                        state = 1;
                    }
                }
                _ => {} // 不会执行
            }
        }

        total_collisions
    }
}
```
