## 下载插件

小扣打算给自己的 VS code 安装使用插件，初始状态下带宽每分钟可以完成 1 个插件的下载。假定每分钟选择以下两种策略之一:

使用当前带宽下载插件
将带宽加倍（下载插件数量随之加倍）

请返回小扣完成下载 n 个插件最少需要多少分钟。

注意：实际的下载的插件数量可以超过 n 个


```
impl Solution {
    pub fn least_minutes(n: i32) -> i32 {
        // 逆向思考：从 n 个剩余插件倒推回 0。
        // 正向的"带宽加倍"逆向就是"剩余需求折半"，
        // 正向的"用当前带宽下载"逆向就是"剩余需求减去当前带宽"。
        // 由于带宽每次都翻倍，逆向看每步带宽固定为 1，剩余需求做整除。
        // 贪心：若剩余需求 > 1，折半（等价于正向先加倍更划算），
        // 否则用一次下载完成。
        let mut n = n;
        let mut minutes = 0;

        while n > 1 {
            // 从 n 变到 ceil(n / 2)，对应正向的一次带宽加倍
            n = (n + 1) / 2;
            minutes += 1;
        }

        // 剩余 1 个插件，用一次下载即可（若 n 原本为 0 则不需要）
        if n == 1 {
            minutes += 1;
        }
        minutes
    }
}
```
